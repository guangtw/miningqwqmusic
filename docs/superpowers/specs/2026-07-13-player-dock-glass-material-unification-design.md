# 播放底栏玻璃材质全局统一设计

## 目标

将项目内所有当前呈现为半透明、毛玻璃、磨砂或悬浮玻璃的界面统一为播放底栏的材质效果。普通实体内容卡片与列表行不新增玻璃效果。

## 视觉基准

播放底栏是唯一材质基准。所有目标表面复制对应主题下播放底栏的光学参数：

- 相同的半透明底色与渐变高光；
- `24px` 背景模糊；
- `170%` 饱和度；
- 相同的外描边、顶部内高光与悬浮阴影；
- 相同的深色与浅色主题映射；
- 相同的不支持 `backdrop-filter` 时的实体背景降级策略。

“完全复制”指材质参数一致，不改变各组件原有圆角、尺寸、布局、层级和交互行为。

## 覆盖范围

统一所有当前已使用 `backdrop-filter`，或在视觉上承担玻璃悬浮层职责的表面，包括：

- 播放底栏及其浮动弹出控件；
- 浮动主导航；
- 账户、设置、一起听等工具抽屉；
- 登录与账户弹窗；
- 歌单与播放队列抽屉；
- 搜索输入壳、模式切换器及玻璃搜索面板；
- 详情页中现有的玻璃控制层；
- 其他现有玻璃工具条、弹出层和悬浮面板。

不覆盖普通实体内容卡片、普通列表行、页面背景，以及玻璃容器内部仅用于分组的纯色衬层。

## 实现结构

在 `app/globals.css` 中建立一组以播放底栏为源的统一材质 token，并让所有目标选择器消费同一套值。保留组件现有类名，使用集中式选择器映射完成迁移，避免为纯视觉调整修改业务组件结构。

嵌套衬层不重复应用 `backdrop-filter`。只有最外层玻璃表面执行背景采样，内部区域使用共享的轻量半透明填充，从而避免叠加模糊、闪烁和额外合成开销。

深色与浅色主题分别读取对应的播放底栏 token；不得为单个抽屉或弹窗保留另一套独立玻璃配方。

## 兼容与降级

- 同时声明标准 `backdrop-filter` 与 `-webkit-backdrop-filter`。
- 在不支持背景模糊的浏览器中使用与主题匹配的高不透明度实体表面。
- 尊重现有 `prefers-reduced-motion` 规则；本次不增加材质动画。
- 保持文本、焦点环和边界在深浅主题中的可读性。

## 验证

1. 增加或扩展材质回归测试，证明目标玻璃选择器使用播放底栏的同一套参数。
2. 运行完整 Vitest、lint 与 Next.js 生产构建。
3. 在浏览器中验证桌面与移动端的深色、浅色主题。
4. 检查浮动导航、搜索、工具抽屉、账户弹窗、歌单抽屉、播放底栏与详情控制层。
5. 检查无横向溢出、无重复模糊、无明显闪烁、无不可读文字或消失边框。

## 不在范围内

- 不重做布局、动效或组件结构；
- 不把普通内容卡片改成玻璃；
- 不修改播放、登录、同步或搜索业务逻辑；
- 不引入新的 UI 依赖。
