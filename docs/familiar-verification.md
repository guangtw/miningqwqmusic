# 熟人暗号：前端与题面协议

用户在「个人中心 → 会员申请」敲门对暗号，通过后得到长期有效的熟客资格。资格不等于会员，也不代表核实过现实身份。判分、抽题、次数、限速都在账户服务；前端不写答案。接口、规则、迁移和回滚见 [后端契约](familiar-backend-contract.md)。

本仓库是公开的：真实题目、答案和能搜到的线索不进 Git，包括文档和测试。定稿题库放开发机的 `.local/`（已忽略）。题面也别写能搜到人或学校的原名。

## 流程

入口组件 `FamiliarEntry`（`src/frontend/components/FamiliarQuest.tsx`）。验证没开放或接口不存在时入口不出现，普通申请不受影响。

1. 敲门：查 `GET /membership/familiar`。已有资格看卡；`nextChallengeAt` 没到期就 `POST challenge {}` 恢复原题；否则让用户选时期，**不自动抽题**。
2. 抽单曲：每个公开时期一张唱片，`canUseRandom` 时多一张白标（`periodId: null`）。
3. 答题：挑战的两题是 A、B 两面。`any` 答一面就能落针；`all` 两面都答才能落针。
4. 落针：提交后至少转两秒再出结果。失败只说「放不出声」，保留已填内容，不说错在哪面。
5. 结果：通过开门发熟客卡；次数用完或题被收回显示打烊和倒计时，到期后由用户点击才能再抽。

约束：验证 POST 不自动重试。没拿到明确结果时先查资格，已通过就开门，否则恢复挑战并显示剩余次数。答案只在组件状态里，不进地址、本地存储、控制台和埋点。文案里不出现「陌生人」，也不承诺先后顺序和结果。

## 题面协议

后端只下发一段 `prompt`。展示形式写在题干后面的 `@` 行里，和题干一起存（解析见 `src/frontend/lib/familiar.ts`）。后台编辑器会替你拼这些行，并实时预览；加题、换题都不用发前端。

```text
这间办公室门牌上写的是谁？
@stage plaque
@kicker 某某办公室
@suffix 老师
@hint 只写姓就行。
```

| `@stage` | 题型 | 样子 | 用到的其他字段 |
| --- | --- | --- | --- |
| `tracklist` | 单选（默认） | 唱片背面的曲目单 | `hint` |
| `chalk` | 单选 | 黑板，粉笔圈字 | `kicker` 黑板抬头，`hint` |
| `signboard` | 单选 | 旧名划掉，翻牌出新名 | `was` 旧名，`hint` |
| `dorms` | 单选，必须两个选项 | 两栋楼，点一栋开店 | `kicker` 店名，`hint` |
| `idcard` | 单选 | 学生证，盖章 | `kicker` 栏目名，`hint` |
| `notebook` | 填空（默认） | 横线本 | `fields`、`suffix`、`hint` |
| `roster` | 填空 | 田字格点名册 | `kicker`、`fields`（`甲\|乙`，最多两格）、`suffix`、`hint` |
| `plaque` | 填空 | 铜门牌 | `kicker`、`suffix`、`hint` |

认不出的形式、和题型对不上的形式、`dorms` 选项不是两个时，都退回默认样式。整段 `prompt` 上限 500 字。

## 录入和上线

后台「会员管理 → 熟人暗号」管理开关、时期、题库版本、资格和限速。「导入定稿题库」接受这样的 JSON，按「建停用时期 → 存题 → 配固定必答并启用」的顺序写入；每导一次都会新建，只导一次：

```json
{
  "periods": [{"key": "u", "label": "公开标签", "sortOrder": 10, "passRule": "all", "required": ["a", "b"]}],
  "questions": [{"key": "a", "period": "u", "title": "内部标题", "group": "内部分组", "kind": "text", "prompt": "题干", "answers": ["答案"]}]
}
```

上线顺序：发布兼容后端并保持 legacy → 发布前端 → 录入题库 → 开启验证 → 配置保护空位 R 和普通发码 → 切换 familiar-first。切换和上线时间由用户决定。

## 怎么出题

每道题要让参与过的人认得出来，外人猜不到、搜不到：

- 适合：圈内称呼、共同命名、共同口误、固定接话、经历中的梗。提示要够清楚，别让人猜「你脑子里那件事」。
- 不要用生日、电话、学号、身份证、住址、账号密码或验证码。题目和答案都可能被截图。
- 不写能搜到人或学校的原名，也别用公开网名、全网能查到的简介。
- 同一个外号反复当不同题的答案，不会增加识别力，一次外传会影响多题。
- 题多不一定好：某圈子的朋友只会一道时，题库越大首轮遇到它的机会越小。至少两道启用题才能开放，2 到 5 道时后台会提醒题库偏小，提醒不代表 6 道就安全。
- 时期标签是公开的，别写不想外传的群名或个人信息。时期只是用户自选，不增加身份可信度。

答案写入后取不回，编辑要重新填完整集合，修改生成新版本。发现外传时用「停用整题」。

## 字体

黑板、田字格用 Long Cang，题面用 Noto Serif CJK SC，都是子集（`src/frontend/assets/fonts/familiar-*.woff2`），只在打开对暗号时下载。题面或界面加了新字要重新子集化，命令见 `src/frontend/styles/familiar.css` 文件头；没收进去的字会落到系统字体。
