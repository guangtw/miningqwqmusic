# 登录会话与 Cookie 链路

## 2026-10-31 复现与修复

线上隔离账号的复现顺序为：注册取得有效刷新 Cookie → 读取音质接口返回 200 → 使用同一个 Cookie 调用账户续期返回 401，响应同时清除 Cookie。

原因是音乐权限检查在服务器内部调用了 `miningqwqlogin` 的 `POST /api/account/auth/refresh`。账户服务将旧刷新令牌作废并签发新 Cookie，但服务器内部请求的 `Set-Cookie` 没有经过音乐接口返回浏览器。浏览器继续保存已被作废的旧令牌，随后就无法恢复会话。账户续期接口还会在所有错误（包括限流及临时故障）上删除 Cookie，放大了问题。

Cookie 原有的 Secure、HttpOnly、SameSite=Lax 和 30 天有效期均保留。access token 默认 15 分钟，只存在浏览器内存；签名密钥和刷新会话数据库不变更。

## 账户服务约定

- `POST /api/account/auth/refresh` 是浏览器续期入口，成功时继续使用一次性刷新令牌轮换，并返回新 Cookie。
- 续期失败不写删除 Cookie 的响应头，防止较晚到达的失败响应覆盖另一标签页刚取得的新 Cookie。无效、过期或撤销的令牌仍返回 401，不能取得新 access token。
- `POST /api/account/auth/logout` 和退出全部设备继续显式撤销会话、清除 Cookie。
- 新增 `GET /api/account/auth/session`，校验 Cookie 对应的未撤销、未过期会话，只返回播放授权快照；不轮换令牌、不延长会话、不签发 access token，也不设置 Cookie。
- `auth/session` 与 `auth/refresh` 均使用 `Cache-Control: no-store`。代理继续逐条转发账户接口的 `Set-Cookie`，Nginx 不缓存用户响应。
- 无关 Cookie 的编码损坏不会阻止正常刷新 Cookie 被读取。

账户服务源码位于独立的 `miningqwqlogin` 仓库，本仓库保留音乐 BFF 与网页客户端。

## 网页与音乐 BFF

音乐 BFF 的权限探测改用只读 `auth/session`，不再隐式调用账户续期。确实失效的 bearer token 会要求浏览器续期并重试，账户服务暂时不可达时不会把故障误报为账号已过期。

网页使用同源 Web Locks 串行处理多标签页的续期、登录和退出请求，避免共享 Cookie 被同时轮换。单页并发请求继续合并为一次续期；较晚返回的旧 token 401 不会重复刷新已经更新的 token。登录或退出后，旧的异步会话请求不能覆盖新的账号状态。

网络中断、429、5xx 会保留已恢复的账号状态并退避重试。初次恢复期间的临时错误不会被判为游客。网络恢复、页面回到前台和 access token 即将过期时会重新检查会话。跨标签页只同步登录/退出事件，不把 access token 或密码写入持久化存储。

Web Locks 不可用的浏览器仍有单页并发合并和错误 Cookie 保护；跨标签页串行保证依赖浏览器支持 Web Locks。浏览器清除 Cookie、用户主动退出、服务端撤销会话或刷新令牌真正过期时仍需重新登录。此前已被作废且丢失新 Cookie 的会话不能恢复，需要登录一次。

## 验证

- `miningqwqlogin`：30 项测试，包括只读会话多次检查后仍可续期、旧令牌被拒绝、403/429/503 不删除 Cookie、退出与撤销生效。
- `miningqwqmusic`：93 项单元/集成测试，包括播放与音质检查不消费 Cookie、过期 bearer 触发浏览器续期、临时故障恢复与退出竞态。
- Chromium 桌面和 Pixel 7：16 项浏览器测试，覆盖共享 Cookie 的双标签页续期、退出广播、断网恢复、九档音质设置以及常规播放与收藏流程。
- 首页截图与 `miningqwqmusic` 提交 `d972db1` 的桌面和手机版本逐像素一致，登录修复不修改界面样式。

2026-10-31 已在候选版本和正式 HTTPS 站点分别使用隔离账号重复最初的复现链路：连续三次播放权限探测后，同一 Cookie 仍可续期；旧 Cookie 返回 401 且不删除新 Cookie；新 Cookie 可再次续期。登录、收藏增删、退出及再次登录全部通过，测试账号按本次生成的 ID 与随机邮箱精确清理。线上桌面及手机版首页、搜索、歌词和播放进度正常，九档音质面板已验证，浏览器无运行错误。

## 部署约束

先部署账户服务的只读接口与 Cookie 保护，再部署网站。复用现有数据库、签名密钥与头像目录，不执行会话清空或数据库迁移；备份服务配置并保留旧代码路径。候选版本仅监听回环地址，检查失败时恢复两项服务的原运行配置。
